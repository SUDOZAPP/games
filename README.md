# SUOU Games for Windows

This repository contains Windows builds of SUOU interactive games and learning tools. Each title is distributed as a single `.exe` with its HTML experience and required assets embedded, so no installation or manual extraction is required.

### System requirements

- Windows 10 or Windows 11
- The latest Microsoft Edge is recommended
- Speakers or headphones for audio and voice features
- Camera access is enabled only when the user selects a camera feature and grants permission

### How to run

1. Select the desired `.exe` file on GitHub.
2. Choose **Download raw file**, or download it from the Releases page.
3. Double-click the downloaded executable.
4. Click or tap the game once before using audio or speech for the first time.

The executable opens the embedded game in a standalone Microsoft Edge application window when Edge is available. Supported builds fall back to the system's default browser when Edge cannot be found. Progress, preferences, and settings are primarily stored on the local device.

### Windows security notice

These executables are not currently signed with a commercial code-signing certificate. Windows SmartScreen may therefore display a warning on first launch. Download files only from the official repository and verify the filename and source before running them.

### Troubleshooting

- **The application does not open:** Make sure Microsoft Edge or another modern browser is installed and up to date.
- **There is no sound:** Click the game once, then check the volume settings in Windows, the browser, and the game.
- **Speech is unavailable:** Install the corresponding Windows system voice. Some titles use browser speech synthesis as a fallback.
- **Camera mode is blank:** Allow camera access when the browser displays the permission prompt.
- **The icon does not update immediately:** Windows may have cached an older icon. Refresh File Explorer or sign out and back in.

### Privacy

No account is required. Progress, preferences, and game state are primarily stored on the user's local device. Camera access is used only when the user explicitly selects a camera feature and grants permission.

### 系統需求

- 建議安裝最新版 Microsoft Edge
- 音效或語音功能需要可用的喇叭或耳機
- 攝影機功能只會在使用者主動選擇並允許權限後啟用

### 使用方式

1. 在 GitHub 中選擇要下載的 `.exe` 檔案。
2. 按下 **Download raw file**，或從 Releases 頁面下載。
3. 下載完成後雙擊執行。
4. 首次播放音效或語音前，請先點擊或觸碰遊戲畫面。

程式會優先在 Microsoft Edge 的獨立應用程式視窗中開啟內嵌遊戲；若找不到 Edge，支援此功能的版本會改用系統預設瀏覽器。遊戲進度、偏好與設定主要保存在本機裝置上。

### Windows 安全提醒

這些 EXE 尚未使用商業程式碼簽章憑證簽署，因此 Windows SmartScreen 可能在第一次執行時顯示提醒。請只從本儲存庫的正式頁面下載，並確認檔名與來源後再執行。

### 疑難排解

- **程式沒有開啟：** 確認 Microsoft Edge 或其他現代瀏覽器已安裝並更新至最新版。
- **沒有聲音：** 先點擊遊戲畫面，再檢查 Windows、瀏覽器與遊戲內的音量設定。
- **語音無法播放：** 確認 Windows 已安裝對應語言的系統語音；部分遊戲會使用瀏覽器語音合成作為備援。
- **攝影機模式沒有畫面：** 在瀏覽器的權限提示中允許攝影機存取。
- **ICON 沒有立即更新：** Windows 可能暫存舊圖示；請重新整理檔案總管或重新登入。

### 隱私

遊戲不需要建立帳號。進度、偏好與遊戲狀態主要保存在使用者的本機裝置。攝影機只會在使用者主動選擇相關功能並授權後啟用。
